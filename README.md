# 📘 Nitro Redemption & Account Setup Documentation

Practical workflow reference for Discord Nitro gift redemption, profile registration, and account risk isolation.

---

## 🧩 Section 1: Minecraft Profile Initialization
1. Navigate to official portal at `minecraft.net` and authenticate using your primary Microsoft account.
2. Click **Set Up Profile**.
3. Choose an In-Game Name (IGN). Check tag availability on [NameMC](https://namemc.com) to confirm the handle is untaken.
4. Confirm profile creation.

---

## 🎁 Section 2: Nitro Redemption Workflow
1. **Account Isolation**: When testing gift procedures, always isolate trials on secondary accounts (alts) rather than primary developer profiles.
2. **Gift Link Extraction**: Generate and claim gift tokens via browser gift URL.
3. **Payment Cycle Management**: Ensure test billing cycles are audited in payment settings before renewal periods.
